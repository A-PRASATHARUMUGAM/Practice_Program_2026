4. Create main.mjs file > import the express to your index file 

    - Server Setup 

            import express from 'express';

            const app = express();
            const port = 3000;

            app.get('/', (req, res) => {
                    res.send('Hello World!');
            });

            app.listen(port, () => {
                    console.log(`Example app listening on port ${port}`);
            });

9. Install nodeman Package

        - 1. nodemon - nodemon is a tool that helps develop Node.js based applications by automatically restarting the node application when file changes in the directory are detected.

            - npm i install nodemon 

            - Start Server Method 1: nodemon main.js 

            - Start Server Method 2: 

                    -1. Create folder ./src/index.mjs ;

                    -2. package.json >  "main":"index.js" -> "main":"index.mjs"

                    -3. package.json > scripts > "start:dev":"nodemon ./src/index.mjs"  -> Nodemon Indicate to index.mjs and it Automatically Run Node.js 

                    -4. package.json > scripts > "start":"node ./src/index.mjs"   -> Which File to start 

                    -5. Start Server -> npm run start:dev

                                -- SQL - Commands --

1. Show the All DataBase 

    - show databases;   


2. Create DataBase

    - CREATE DATABASE database_name;


3. Use the DB which DB you want 

    - use database_name; 


4.  Drop Database / Delete the Data Base

    - DROP DATABASE database_name;


5. ALTER DATABASE - Read only in the DataBase you can't about to DROP DB 

    Read Only: ON
            - ALTER DATABASE read only = 1; 

    Read Only: OFF

             - ALTER DATABASE read only = 0;  


6. DB > Create Table & Data Types 

            - CREATE TABLE table_name(column_name datatype);

    Ex: 
            create table stores(
                product_id int, 
                product_name varchar(250),
                product_price decimal(10,2),
                uploaded_date date
            );


7. Show the all Record for Table 

            - SELECT * FROM table_name;


8. Rename Tables 

            - RENAME table old_table_name to new_table_name 

9. Drop Table 

            - DROP TABLE table_name;


10. ALTER TABLE - Add the Extra column_name

            - ALTER TABLE table_name;
            - Add column_name;

    Ex:

            ALTER TABLE stores 
            ADD product_qnt varchar(10);


11. Rename the table Column Name 

            - ALTER TABLE table_name;
            - RENAME COLUMN old_column_name to new_column_name


12. Modify the table column Name datatype 

            - ALTER TABLE table_name
            - MODIFY COLUMN column_name varchar(255)

    - If you want to Move - 

            - first; - Move the column first 
            - after product_price - Move to after productprice

    - ALTER TABLE table_name

    - If you want to Move -

14. Remove the Specific column_name

15. Insert Rows - Single / Multiple  

    Syntax:

        INSERT INTO table_name
        VALUES(product_id, product_name, product_price, uploaded_date);


    Ex:
        INSERT INTO stores
        VALUES(1, "Computer", 2000, "2026-07-03"),
                (2, "Keybaord", 1000, "2026-07-03"),
                (3, "Mouse", 500, "2026-07-03"),
                (4, "Monitor", 4000, "2026-07-03"),
                (5, "Pendrive", 600, "2026-07-03");


16. Insert Specific Rows only 

    Syntax: 
        
        INSERT INTO table_name (product_name, product_price)
        VALUES("Computer", 2000,);

    Ex:

        INSERT INTO stores (product_name, product_price)
        VALUES("Computer", 2000);
               

17. Find/Show the Specific Column

        Syntax:

            SELECT column_name1, column_name...n from table_name;

        
        Ex:

            Select product_id, product_name from stores;


18. Find/Show the Specific Column name as alise name

       Syntax:

            SELECT column_name1 as alise_name from table_name;

        
        Ex:

            Select product_id, product_name as product_list from stores;

19. Find/Show the Specific Column Base on Values. (Condition to find the data)


        Syntax:

            SELECT * from table_name where column_name = id/names/value

        Ex:   (Not Equal, Names, Value)

            Select * from stores where product_id = 4 ;
                        (OR)
            Select * from stores where product_id != 4 ;
                        (OR)
            Select product_id, product_name from stores  where product_id != 4;
                        (OR)
            Select * from stores where product_price > 1000;
                        (OR)
            Select * from stores where uploaded_date is null;
                         (OR)
            Select * from stores where uploaded_date is not null;

20. UPDATE Rows all/Specific

         Syntax:

            UPDATE table_name 
            set column_name = "value"
            where which_id = id

        Ex:

            UPDATE stores
            set uploaded_date = "2026-07-04",
            set product_name = "Power Cable ",
            set product_price = null
            where product_id = 6 

21. DELETE Rows all/ Specific (Important)

        Syntax:

            DELETE from table_name;  -> It is Delete all data 
            Where which_id = id
            
        Ex: 

            DELETE from stores
            where product_id = 6

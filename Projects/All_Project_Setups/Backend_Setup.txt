
-- Backend Project Structure --

📁 Backend (Node.js + Express + Prisma + MySQL)

Repository Pattern (REP) + Service Layer (Recommended)


--- Setup Start Here ---

    
1. Install the Node Package 
    - npm init -y 

2. Install Express 
    - npm install express 

3. Create the Git repository (Option but recommended)
    - git init 

4. Create main.mjs file > import the express to your index file 

    - Server Setup 

            import express from 'express';

            const app = express();
            const port = 3000;

            app.get('/', (req, res) => {
                    res.send('Hello World!');
            });

            app.listen(port, () => {
                    console.log(`Example app listening on port ${port}`);
            });


5. Implement the Module 
    
    - 1. package.json >  "type": "commonjs" ->  "type":"module" -> Because Using ESC Module require instead using Import


6. Install nodeman Package

        - 1. nodemon - nodemon is a tool that helps develop Node.js based applications by automatically restarting the node application when file changes in the directory are detected.

            - npm i install nodemon 

            - Start Server Method 1: nodemon main.js 

            - Start Server Method 2: It is automatically run

                    -1. Create folder ./src/index.mjs ;

                    -2. package.json >  "main":"index.js" -> "main":"main.mjs"

                    -3. package.json > scripts > "start:dev":"nodemon ./src/main.mjs"  -> Nodemon Indicate to index.mjs and it Automatically Run Node.js 

                    -4. package.json > scripts > "start":"node ./src/main.mjs"   -> Which File to start 

                    -5. Start Server -> npm run start:dev  
                    

7. Create the Routes folder > user.routes.mjs 

            - 1. import express from "express";

            - 2. const router = express.Router();

            - 3. call router.get()

            - 4. export default router;

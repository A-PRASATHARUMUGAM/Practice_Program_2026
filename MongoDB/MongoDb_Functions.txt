1. Find 

            --- 1.db.users.find({name:"Kandhan"})  -> Find the specific one 

            {
            _id: ObjectId('6a22a2e0d9f4555c806744c6'),
            name: 'Kandhan',
            Age: 22,
            Gender: 'Male'
            }


2. Project / Projection 
 
                Ex: db.users.find({Query},{Projection})

            --- 1. db.users.find({name:"Kandhan"},{name:true})   -> It is give exact name only

            {
            _id: ObjectId('6a22a2e0d9f4555c806744c6'),
            name: 'Kandhan'
            }


3. Sort  -> Showing the Uppercase first because of ASCII and it Sort the value Ascending and Descending Orders 


     - Sort Ascending Order - 

                    --- 1. db.users.find().sort({name:1})     -> Ascending Order Sort 

                    {
                    _id: ObjectId('6a22a2e0d9f4555c806744c6'),
                    name: 'Kandhan',
                    Age: 22,
                    Gender: 'Male'
                    }
                    {
                    _id: ObjectId('6a22a5fd00104291c513a4ae'),
                    name: 'Priya',
                    Age: 22,
                    Gender: 'Female'
                    }

    - Sort Descending Order - 

                    --- 2. db.users.find().sort({name:-1})     -> Descending Order Sort 

    - Sort Projection + Ascending Order or Descending Order  - 

                1. db.users.find({name:"Kandhan"},{name:true}).sort(name:1) 
                2. db.users.find({name:"Kandhan"},{name:true}).sort(name:-1)


4. Limit - It is showing the limits of the data 


    -- 1. db.users.find().sort({name:1}).limit(2)



5. Update Function 

1.updateOne
    -$set:{} - using the update the value 
    -$unset:{} - Remove Entire Attribute / Column 

2.updateMany 



  1.updateOne + $set:{}

  - db.users.updateOne 

  - db.users.updateOne({name:"Priya"},{$set:{name:"Prasath"}})

Result: 

    {
    acknowledged: true,
    insertedId: null,
    matchedCount: 1,
    modifiedCount: 1,
    upsertedCount: 0
    }

  2.update -> Usign ObjectId 

    -db.users.updateOne({_id:ObjectId('6a22a5fd00104291c513a4ae')},{$set:{Age:25}})


Result:

{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}


  3.updateOne + $unset:{}

    -db.users.updateOne({_id:ObjectId('6a22a5fd00104291c513a4ae')},{$unset:{Age:25}})

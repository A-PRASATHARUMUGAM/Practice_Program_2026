                         -- MongoDB Aggregation Pipelines--


1.skip Function  -> It is skip the record like Ex: Pagination 

2.aggregate()
    -$match     -> If any match it will return 
    -$group     -> Group the values 
    -$sum       -> Sum the value 
    -$max       -> It is choose the hight value (500 + 50 + 100 = 650)  max = 500 | sum =650 
    -$avg       -> It is give the Average Value 
    -$out       -> Overall data store to specific name 
    -$count     -> It is return the count of the value
